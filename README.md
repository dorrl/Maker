# Maker

Maker는 Windows용 네이티브 텍스트·코드 편집기입니다. Rust로 작성했고 Windows의 Win32 및 Rich Edit 컨트롤을 사용합니다.

## 실행

소스에서 `cargo run --release`로 실행할 수 있습니다. 시작 화면에서 파일이나 폴더를 열거나 새 파일을 만들 수 있습니다. 파일이나 폴더를 창으로 끌어 놓거나 명령줄 인자로 전달하는 것도 가능합니다.

~~~powershell
cargo run --release -- .\src\main.rs
~~~

**파일 → 폴더 열기**에서 Windows 탐색기 형태의 폴더 선택 창을 엽니다. 사이드바에서 폴더를 클릭하면 하위 폴더와 파일을 펼치거나 접을 수 있습니다. 키보드로는 좌우 방향키를 사용합니다. 파일 아이콘은 종류별로 다르게 표시됩니다.

탐색기 위의 아이콘으로 새 파일과 폴더를 만들 수 있습니다. 선택한 폴더 또는 파일이 있는 폴더에 추가됩니다. 파일이나 폴더를 선택한 뒤 **F2**를 누르고 새 이름을 입력하면 열린 탭에도 새 경로가 적용됩니다.

**Shift+클릭**으로 연속된 항목을 선택하고 **Ctrl+클릭**으로 선택에 개별 항목을 추가하거나 뺄 수 있습니다. 찾기, 바꾸기, 이름 바꾸기 입력창은 편집기 오른쪽 위에 열립니다.

탐색기에서 항목을 선택하고 **Delete**를 누른 뒤 확인하면 휴지통으로 이동합니다. 파일이 열린 상태에서 미저장 내용이 있으면 해당 탭에 초안이 남습니다.

ZIP, 7z, RAR, TAR 및 압축된 TAR은 화살표로 트리를 펼칠 수 있습니다. 텍스트 항목은 읽기 전용으로 열립니다. 압축 파일 이름을 클릭하거나 Enter를 누르면 압축을 풀 위치를 고르는 창이 열립니다. 선택한 위치에 새 폴더를 만들어 압축을 풉니다. 이 기능은 Windows의 압축 구성 요소가 설치된 환경에서 사용할 수 있습니다.

사이드바 경계를 끌면 너비를 조절할 수 있습니다. 경계를 반대편 끝까지 끌거나 **보기** 메뉴의 배치 명령을 선택하면 좌우 위치를 바꿀 수 있습니다. 위치와 너비는 다음 실행에도 적용됩니다. 사이드바 경계를 두 번 클릭하면 기본 너비로 돌아옵니다.

작업 폴더 검색은 열린 탭의 미저장 내용도 검색합니다. 검색 인덱스는 최대 1,500개 파일을 포함하며 종속성·빌드 폴더와 3 MiB를 넘는 검색 대상 파일은 건너뜁니다.

일반 실행 시 이전 창의 위치, 크기, 최대화 상태와 작업 폴더, 펼친 폴더, 열린 탭, 분할 상태, 커서, 미저장 내용을 불러옵니다. 미저장 내용은 복원용 초안으로 보관되며 파일에 반영하려면 저장해야 합니다. 이전 터미널 탭에서는 셸이 새로 시작됩니다. **Ctrl+Shift+N**은 시작 화면이 있는 별도의 창을 엽니다.

## Git

사이드바 아이콘 또는 **Ctrl+Shift+E**와 **Ctrl+Shift+G**로 탐색기와 소스 제어를 전환합니다. Git이 설치되어 있고 작업 폴더가 Git 저장소 안에 있으면 브랜치와 변경 파일이 표시됩니다. 파일을 클릭하면 편집기에서 변경 내용을 확인할 수 있습니다. 여러 파일을 선택해 스테이지하거나 해제할 수 있고, 커밋 메시지를 입력해 스테이지한 변경 사항을 커밋할 수 있습니다.

변경 목록 아래에는 최근 커밋의 부모 관계와 브랜치·태그 이름이 표시됩니다. **커밋** 메뉴에서 기준 브랜치를, **비교** 메뉴에서 함께 표시할 브랜치를 선택합니다. 자동 비교는 기준 브랜치의 업스트림을 사용합니다. 커밋을 두 번 클릭하거나 Enter를 누르면 상세 변경 내용을 엽니다.

## 터미널

**터미널** 메뉴에서 PowerShell이나 명령 프롬프트 탭을 열 수 있습니다. 새 탭은 작업 폴더에서 시작하며, 작업 폴더를 열지 않았으면 현재 파일의 폴더를 사용합니다. 탭마다 셸과 작업 경로가 따로 유지됩니다. 패널을 숨겨도 탭의 셸은 계속 실행됩니다.

패널 경계를 끌어 크기를 조절하고, 작업 영역 가장자리로 끌어 아래·왼쪽·오른쪽에 배치할 수 있습니다. 위치는 메뉴에서도 선택할 수 있으며, 위치와 크기는 저장됩니다.

| 동작 | 키 |
| --- | --- |
| 터미널 표시·숨기기 | Ctrl+백틱 |
| 새 PowerShell 탭 | Ctrl+Shift+백틱 |
| 터미널에 포커스가 있을 때 탭 이동·닫기 | Ctrl+Tab, Ctrl+Shift+Tab, Ctrl+F4 |
| 터미널 선택 영역 복사, 붙여넣기 | Ctrl+Shift+C, Ctrl+V |

터미널은 Windows 10 1809 이상에서 동작하며 한글 출력, ANSI 색상과 기본 화면 제어를 지원합니다.

UTF-8 텍스트를 열고 저장하며 기존 파일의 BOM과 LF/CRLF 형식을 보존합니다. 기본 테마는 어두운 색입니다. 설정 메뉴에서 테마, 글꼴, 글자 크기, 들여쓰기와 자동 줄바꿈을 바꿀 수 있습니다. 네이티브 설정은 사용자별 Maker 설정 파일에 저장됩니다.

## 언어 기능

파일 확장자에 따라 Rust, JavaScript, TypeScript, JSON, HTML, CSS, Python, Go, Java, C/C++, C#, Ruby, PHP, XML, Markdown, YAML, Shell, INI/TOML, SQL의 구문을 강조합니다. 코드에서는 함수·타입·키워드·리터럴을 구분하며, 괄호 (), [], {}는 중첩 깊이에 따라 짝에 같은 색을 씁니다. 짝이 없는 괄호는 붉게 표시되며 문자열과 주석의 괄호는 해당 구문의 색을 유지합니다.

입력 중 자동완성 후보가 나타나면 방향키로 고르고 **Tab**이나 **Enter**로 적용할 수 있습니다. **Ctrl+Space**로 직접 열 수도 있습니다. 지원 언어에서는 현재 파일의 스코프에 있는 변수·함수·타입, 확인 가능한 멤버, 언어 키워드, 내장 이름과 스니펫을 제안합니다. 나머지 형식에서는 언어 키워드와 파일 내 단어를 제안합니다. 후보는 열려 있는 파일의 내용과 언어별 기본 목록에서 가져옵니다.

Rust, JavaScript, TypeScript, Python, Go, Java, C/C++, C#에서는 편집기에서 **F2**를 눌러 현재 파일에서 확인되는 심볼의 선언과 참조를 함께 바꿀 수 있습니다. 여러 파일에 걸친 변경과 언어 서버의 타입 기반 참조 분석은 지원하지 않습니다.

기존 웹 버전의 타입 검사, 정의·참조 탐색, 다중 커서, 사용자 지정 단축키는 네이티브 버전에 아직 포함되지 않았습니다. 이전 Quill/Maker 브라우저 프로필의 설정은 자동으로 이전되지 않습니다.

## 빌드

Windows x64, Rust MSVC 도구 체인, Windows SDK와 C++ Build Tools가 필요합니다. Cargo 외부 의존성은 없습니다.

~~~powershell
cargo test --offline
cargo build --release --offline
.\target\release\maker.exe
~~~
