# Maker

Maker는 Windows용 네이티브 텍스트·코드 편집기입니다. Rust로 작성했고 Windows의 Win32 및 Rich Edit 컨트롤을 사용합니다.

## 실행

소스에서 `cargo run --release`로 실행할 수 있습니다. 시작 화면에서 파일이나 폴더를 열거나 새 파일을 만들 수 있습니다. 파일이나 폴더를 창으로 끌어 놓거나 명령줄 인자로 전달하는 것도 가능합니다.

~~~powershell
cargo run --release -- .\src\main.rs
~~~

**파일 → 폴더 열기**에서 Windows 탐색기 형태의 폴더 선택 창을 엽니다. 사이드바에서 폴더를 클릭하면 하위 폴더와 파일을 펼치거나 접을 수 있습니다. 키보드로는 좌우 방향키를 사용합니다. 파일 아이콘은 종류별로 다르게 표시됩니다.

탐색기 위의 아이콘을 누르면 선택한 폴더 또는 선택한 파일의 상위 폴더에 새 이름을 입력할 행이 생깁니다. 파일이나 폴더를 선택하고 **F2**를 누르면 해당 행에서 이름을 바꿀 수 있으며, 열린 탭에도 새 경로가 적용됩니다. **Enter**로 확정하고 **Esc**로 취소합니다.

**Shift+클릭**으로 연속된 항목을 선택하고 **Ctrl+클릭**으로 선택에 개별 항목을 추가하거나 뺄 수 있습니다. 찾기, 바꾸기, 심볼 이름 바꾸기 입력창은 편집기 오른쪽 위에 열립니다. 편집기 왼쪽에는 실제 파일의 줄 번호가 표시되며, 자동 줄바꿈으로 이어지는 행은 같은 번호를 공유합니다.

탐색기에서 항목을 선택하고 **Delete**를 누른 뒤 확인하면 휴지통으로 이동합니다. 파일이 열린 상태에서 미저장 내용이 있으면 해당 탭에 초안이 남습니다.

ZIP, 7z, RAR, TAR 및 압축된 TAR은 화살표로 트리를 펼칠 수 있습니다. 텍스트 항목은 읽기 전용으로 열립니다. 압축 파일 이름을 클릭하거나 Enter를 누르면 압축을 풀 위치를 고르는 창이 열립니다. 선택한 위치에 새 폴더를 만들어 압축을 풉니다. 이 기능은 Windows의 압축 구성 요소가 설치된 환경에서 사용할 수 있습니다.

사이드바 경계를 끌면 너비를 조절할 수 있습니다. 경계를 반대편 끝까지 끌거나 **보기** 메뉴의 배치 명령을 선택하면 좌우 위치를 바꿀 수 있습니다. 위치와 너비는 다음 실행에도 적용됩니다. 사이드바 경계를 두 번 클릭하면 기본 너비로 돌아옵니다.

작업 폴더 검색은 열린 탭의 미저장 내용도 검색합니다. 검색 인덱스는 최대 1,500개 파일을 포함하며 종속성·빌드 폴더와 3 MiB를 넘는 검색 대상 파일은 건너뜁니다.

일반 실행 시 이전 창의 위치, 크기, 최대화 상태와 작업 폴더, 펼친 폴더, 열린 탭, 분할 상태, 커서, 미저장 내용을 불러옵니다. 미저장 내용은 복원용 초안으로 보관되며 파일에 반영하려면 저장해야 합니다. 이전 터미널 탭에서는 셸이 새로 시작됩니다. **Ctrl+Shift+N**은 시작 화면이 있는 별도의 창을 엽니다.

버튼, 탐색기 항목, 탭, 메뉴 전환에 짧은 시각 효과가 적용됩니다. Windows에서 애니메이션 효과를 끄면 상태가 즉시 바뀝니다.

## 새 탭과 화면 분할

**Ctrl+T** 또는 탭 바의 **+**를 누르면 파일·폴더·URL을 여는 검색창이 나옵니다. 상대 경로와 이름은 현재 편집 중인 파일의 상위 폴더나 열어 둔 폴더를 기준으로 찾습니다. 활성 탭에 경로가 없으면 작업 폴더를 사용합니다. 드라이브 문자가 포함된 절대 경로도 입력할 수 있습니다.

폴더를 열면 편집기 안에 트리가 표시됩니다. 화살표로 하위 폴더를 펼치고, 이름을 클릭하면 현재 탭에서 엽니다. **Ctrl+클릭**과 **휠 클릭**은 새 탭에서 엽니다. 검색창에 `..`를 입력하면 상위 폴더를 열 수 있습니다.

`http://` 또는 `https://` 주소는 Windows의 `curl.exe`로 GET 요청을 보내고 응답을 읽기 전용 탭에 표시합니다. `example.com`처럼 프로토콜을 생략한 주소는 이름이 정확히 일치하는 로컬 항목이 없으면 HTTPS로 엽니다. UTF-8 텍스트 응답을 최대 4 MiB까지 표시하며, 요청 제한 시간은 15초입니다.

편집기 탭 또는 탐색기의 파일·폴더를 편집기 네 가장자리로 끌면 가로 또는 세로로 두 영역을 나눕니다. 경계를 드래그해 크기를 조정할 수 있습니다. 가운데에 놓으면 별도 창으로 열립니다. 탭 바 안에서 드래그하면 탭 순서가 바뀝니다. 터미널 탭을 패널 밖으로 끌면 실행 중인 터미널 세션이 별도 창으로 이동합니다.

탐색기 폴더를 사이드바 아래쪽에 놓거나 **도구 → 보조 탐색기 열기**에서 고르면 보조 탐색기가 열립니다. 경계를 드래그해 높이를 바꿀 수 있고, **도구 → 보조 탐색기 닫기**로 접을 수 있습니다. 기본 창을 다시 열면 폴더 탭과 분할 배치가 복원됩니다.

분할 영역마다 탭 바와 현재 파일 경로를 표시합니다. 다른 영역의 탭 바로 끌면 탭을 그쪽으로 옮길 수 있습니다. **Ctrl+Shift+N**으로 연 Maker 창이나 떼어낸 Maker 창으로 끌면, 받는 창에서 편집 탭이나 터미널 탭이 놓일 위치를 표시합니다.

상단 **설정** 또는 **Ctrl+,**로 별도 설정 창을 엽니다. **F11**로 전체 화면을 전환합니다. 다음 일반 실행 시 작업 폴더, 탭 그룹, 최대화 또는 전체 화면 상태를 복원합니다.

탐색기 또는 폴더 탭에서 **Ctrl+C**로 선택한 파일·폴더를 복사하고, 대상 폴더를 선택한 뒤 **Ctrl+V**로 붙여넣습니다. 파일을 선택한 상태에서는 그 파일의 상위 폴더에 붙여넣습니다. 파일 경로는 Windows 탐색기와 주고받을 수 있고, Windows 클립보드에 접근할 수 없는 경우에는 Maker 창 사이에서 복사할 수 있습니다. `.exe` 파일은 두 번 클릭하면 Windows로 실행을 요청합니다.

## 구조 보기와 외부 브라우저

`.json`, `.yaml`, `.yml`, `.html`, `.htm`, `.svg`를 열면 파일 경로 오른쪽에 **원문**, **Pretty Print**, **트리**가 표시됩니다. **Pretty Print**는 들여쓴 텍스트를 읽기 전용으로 표시합니다. JSON은 키 순서와 중복 키, 숫자 표기를 유지합니다. YAML의 주석과 원래 인용 방식은 원문에서 확인할 수 있습니다.

**트리**에서 객체나 배열 행을 클릭하거나 방향키 **←**·**→**를 눌러 접고 펼칩니다. **모두 펼치기**와 **모두 접기**도 사용할 수 있습니다. 정돈된 보기와 트리는 8 MiB 이하의 문서에서 사용할 수 있으며, 보기 전환은 파일과 미저장 내용을 변경하지 않습니다.

HTML과 SVG는 요소와 속성도 트리에 표시합니다. HTML 파일이나 웹에서 불러온 HTML에서 **브라우저에서 열기**를 누르면 저장된 파일 또는 요청이 도착한 URL을 외부 브라우저에 엽니다.

## 언어와 테마

별도 **설정** 창에서 한국어와 영어를 선택할 수 있습니다. 문구는 `src/locales/ko.json`과 `src/locales/en.json`에서 관리합니다.

기본 테마는 **다크**, **라이트**, **그래파이트**, **미드나이트**, **페이퍼**입니다. `src/themes`에 테마마다 UI, 아이콘, 구문 색상 정의가 들어 있습니다. 수정할 테마의 JSON을 `%LOCALAPPDATA%/Maker/themes`에 같은 이름으로 두면 다시 테마를 적용할 때 지정한 색을 사용합니다. 색은 0~255 범위의 RGB 배열입니다.

## Git

사이드바 아이콘 또는 **Ctrl+Shift+E**와 **Ctrl+Shift+G**로 탐색기와 소스 제어를 전환합니다. Git이 설치되어 있고 작업 폴더가 Git 저장소 안에 있으면 브랜치와 변경 파일이 표시됩니다. 파일을 클릭하면 편집기에서 변경 내용을 확인할 수 있습니다. 여러 파일을 선택해 스테이지하거나 해제할 수 있고, 커밋 메시지를 입력해 스테이지한 변경 사항을 커밋할 수 있습니다.

Git 비교 화면에서는 추가된 줄과 삭제된 줄에 각각 글자색과 배경색이 적용됩니다. 테마 JSON의 `diff`에서 `added_text`, `added_background`, `removed_text`, `removed_background`를 RGB 배열로 지정할 수 있습니다.

변경 목록 아래에는 최근 커밋의 부모 관계와 브랜치·태그 이름이 표시됩니다. **커밋** 메뉴에서 기준 브랜치를, **비교** 메뉴에서 함께 표시할 브랜치를 선택합니다. 자동 비교는 기준 브랜치의 업스트림을 사용합니다. 커밋을 두 번 클릭하거나 Enter를 누르면 상세 변경 내용을 엽니다.

## 터미널

**터미널** 메뉴에서 PowerShell이나 명령 프롬프트 탭을 열 수 있습니다. 새 탭은 작업 폴더에서 시작하며, 작업 폴더를 열지 않았으면 현재 파일의 폴더를 사용합니다. 탭마다 셸과 작업 경로가 따로 유지됩니다. 패널을 숨겨도 탭의 셸은 계속 실행됩니다.

패널 경계를 끌어 크기를 조절하고, 작업 영역 가장자리로 끌어 아래·왼쪽·오른쪽에 배치할 수 있습니다. 위치는 메뉴에서도 선택할 수 있으며, 위치와 크기는 저장됩니다.

터미널 탭을 사이드바에 끌거나 터미널 메뉴에서 **사이드바 옆에 터미널 열기**를 선택하면 탐색기 옆에 터미널 패널이 열립니다. 패널과 편집기 사이 경계를 끌어 너비를 조절할 수 있습니다. 창 사이에서 마지막 편집기 탭이나 터미널 탭을 옮기고 남은 탭이 없으면 원래 창이 닫힙니다.

| 동작 | 키 |
| --- | --- |
| 터미널 표시·숨기기 | Ctrl+백틱 |
| 새 PowerShell 탭 | Ctrl+Shift+백틱 |
| 터미널에 포커스가 있을 때 탭 이동·닫기 | Ctrl+Tab, Ctrl+Shift+Tab, Ctrl+F4 |
| 터미널 선택 영역 복사, 붙여넣기 | Ctrl+Shift+C, Ctrl+V |

터미널은 Windows 10 1809 이상에서 동작하며 한글 출력, ANSI 색상과 기본 화면 제어를 지원합니다.

UTF-8 텍스트를 열고 저장하며 기존 파일의 BOM과 LF/CRLF 형식을 보존합니다. 기본 테마는 어두운 색입니다. 설정 메뉴에서 테마, 글꼴, 글자 크기, 들여쓰기와 자동 줄바꿈을 바꿀 수 있습니다. 네이티브 설정은 사용자별 Maker 설정 파일에 저장됩니다.

## 언어 기능

파일 확장자에 따라 Rust, JavaScript, TypeScript, JSON, HTML, CSS, Python, Go, Java, C/C++, C#, Ruby, PHP, XML, Markdown, YAML, Shell, INI/TOML, SQL의 구문을 강조합니다. 코드에서는 함수·타입·키워드·리터럴을 구분하며, 괄호 (), [], {}는 중첩 깊이에 따라 짝에 같은 색을 씁니다. 짝이 없는 괄호는 붉게 표시되며 문자열과 주석의 괄호는 해당 구문의 색을 유지합니다.

입력 중 자동완성 후보가 나타나면 방향키로 고르고 **Tab**이나 **Enter**로 적용할 수 있습니다. **Ctrl+Space**로 직접 열 수도 있습니다. 지원 언어에서는 현재 파일의 스코프에 있는 변수·함수·타입, 확인 가능한 멤버, 언어 키워드, 내장 이름과 스니펫을 제안합니다. 나머지 형식에서는 언어 키워드와 파일 내 단어를 제안합니다. 후보는 열려 있는 파일의 내용과 언어별 기본 목록에서 가져옵니다.

Rust, JavaScript, TypeScript, Python, Go, Java, C/C++, C#에서는 편집기에서 **F2**를 눌러 현재 파일에서 확인되는 심볼의 선언과 참조를 함께 바꿀 수 있습니다. 여러 파일에 걸친 변경과 언어 서버의 타입 기반 참조 분석은 지원하지 않습니다.

기존 웹 버전의 타입 검사, 정의·참조 탐색, 다중 커서, 사용자 지정 단축키는 네이티브 버전에 아직 포함되지 않았습니다. 이전 Quill/Maker 브라우저 프로필의 설정은 자동으로 이전되지 않습니다.

## 빌드

Windows x64, Rust MSVC 도구 체인, Windows SDK와 C++ Build Tools가 필요합니다. 첫 빌드 전에 문서 파서 의존성을 내려받습니다.

~~~powershell
cargo fetch --locked
cargo test --locked --offline
cargo build --release --locked --offline
cp ./target/release/maker.exe ./Maker.exe
./Maker.exe
~~~
